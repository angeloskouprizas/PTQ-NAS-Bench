[ 0. BENCHMARK GENERATION (Benchmark_scripts) ]
--------------------------------------------------------------------------------

Script      : nas_bench_201_extract_models.py
Description : Extract NATS-Bench weights and divide them into buckets/chunks.
Run Command :
python3 Benchmark_scripts/nas_bench_201_extract_models.py \
    --project_root "." \
    --weights-folder "./NATS_Benchmark/Model_weights/Weights/" \
    --output-root "./outputs/three_way_out" \
    --chunk-size 200

................................................................................

Script      : worker_server_bucket_chunks.py
Description : Execute the PTQ and Fine-Tuning (QAT) process on a specific bucket.
              (Internally imports ptq_main.py and nas_bench_201_workflow_multithread.py)
Run Command :
python3 Benchmark_scripts/worker_server_bucket_chunks.py \
    --project_root "." \
    --bucket_dir "./outputs/three_way_out/bucket_0" \
    --csv_file "./outputs/PTQ_Results/bucket_0_results.csv" \
    --done_file "./outputs/three_way_out/bucket_0/progress_done_ids.txt" \
    --fail_file "./outputs/three_way_out/bucket_0/progress_failed_ids.txt"

[ 1. DATA PROCESSING (PTQ_Conaq/data_processing) ]
--------------------------------------------------------------------------------

Script      : QNP_calc.py
Description : Extract QNP values from NATS-Bench weights.
Run Command :
python3 PTQ_Conaq/data_processing/QNP_calc.py \
    --naszilla_dir "./naszilla" \
    --data_dir "./data" \
    --weights_pattern "./NATS_Benchmark/Model_weights/Weights/NATS-tss-v1_0-3ffb9-full.tara*" \
    --output_dir "./outputs/Final_Merged/" \
    --scheme Q4

................................................................................

Script      : BOPs_calc.py
Description : Calculate and integrate BitOps (FLOPs * bw * ba).
Run Command :
python3 PTQ_Conaq/data_processing/BOPs_calc.py \
    --fp32_csv "./datasets/FP32/edgegpu_dataset_with_flops.csv" \
    --input_dir "./datasets/PTQ_Metrics/" \
    --output_dir "./outputs/Final_Merged/"

................................................................................

Script      : Quant_Acc_merge.py
Description : Merge the Quantized Accuracy results into the dataset.
Run Command :
python3 PTQ_Conaq/data_processing/Quant_Acc_merge.py \
    --acc_dir "./datasets/PTQ_Benchmark/" \
    --input_dir "./datasets/PTQ_Metrics_and_Results/Dataset/" \
    --output_dir "./outputs/Final_Complete_Datasets/"

................................................................................

Script      : FP32_Acc_merge.py
Description : Merge the FP32 baseline accuracy into the dataset.
Run Command :
python3 PTQ_Conaq/data_processing/FP32_Acc_merge.py \
    --fp32_csv "./datasets/FP32/edgegpu_dataset_with_flops.csv" \
    --target_dir "./datasets/BenchMark_Q_schemes/Datasets/FP32_acc"

................................................................................

Script      : lnQNP_lnQNPFP32acc.py
Description : Calculate the Proxy Features for Pareto Ranking.
Run Command (For 3D - ln(QNP+1)):
python3 PTQ_Conaq/data_processing/lnQNP_lnQNPFP32acc.py \
    --input_dir "./datasets/FP32_acc/QNPxFP32acc" \
    --output_dir "./datasets/Final_Features"

Run Command (For 2D - ln(QNP) x FP32_acc):
python3 PTQ_Conaq/data_processing/lnQNP_lnQNPFP32acc.py \
    --input_dir "./datasets/FP32_acc/QNPxFP32acc" \
    --output_dir "./datasets/Final_Features" \
    --multiply_fp32
